# 坤坤日报

摸鱼搞出的个人桌面工作台，欢迎各位大佬提供脑洞一起完善。我是真IKUN，不是小黑子！！！

## 模块
个人计划 / 工作日报 / 阅读打卡 / 每日锻炼 / 记账本 / 心情日记 / 灵感墙
个人计划与阶段目标支持历史档案。

## 使用
1. 到 Releases 下载最新 .7z 压缩包
2. 解压到任意文件夹（不要解压到系统目录）
3. 双击 坤坤日报/坤坤日报.exe
首次启动在本地生成数据文件，数据只存在自己电脑上。

## 环境要求
Windows 10 / 11（64 位），解压即用，无需安装任何运行环境。
