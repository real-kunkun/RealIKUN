# 这个文件夹就是源码

名字叫"本地测试环境"，但**代码只有这一份**，没有别的副本。

## 为什么叫这个名字

这个目录里有一个空文件 `resources/app/LOCAL_TEST_ENV`，程序启动时检测到它就会：

- 数据文件、缓存、单实例锁全部与正式版隔离（用 `%APPDATA%\todo-daily-test`）
- 不接管桌面快捷方式、不写开机自启
- 不检查更新、不自动代替正式版运行

所以它可以和 `C:\MySoft\坤坤日报`（正式安装版）同时开着互不干扰，用来试新功能。

## 代码在哪

```
resources/app/
├── main.js          主进程：窗口/托盘/数据读写/一键更新
├── preload.js       给界面的安全桥
├── app.js           界面逻辑
├── style.css        全部样式（文件顶部有布局不变量说明，改样式前先读）
├── index.html       界面结构
├── data-layer.js    数据结构与版本迁移（SCHEMA_VERSION 在这里）
├── update-check.js  更新检测（三通道并发）
├── tray-menu.html / tray-preload.js   托盘自绘菜单
└── fonts/           随包字体（不要随意换，字体糊了很难看）
```

## 不要直接改这里

```
✗ C:\MySoft\坤坤日报\            ← 正式安装目录，升级时会被整包覆盖，改了也会没
✓ C:\MySoft\todo\坤坤日报本地测试环境\resources\app\   ← 改这里
```

改完用 `node tests/updater.test.js` 自测，再用 `node _pack.js` 打包。
发版流程见 `../../docs/发版手册.md`。
